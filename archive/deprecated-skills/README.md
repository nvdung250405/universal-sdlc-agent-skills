# Deprecated Skills Archive

This directory stores skills that were previously bundled in the pack but have been deprecated and retired from the active packaged inventory:

- `finishing-a-development-branch`: Deprecated in favor of `git-workflow-and-versioning` (Addy Osmani) and `using-git-worktrees` (Superpowers).
- `requesting-code-review`: Deprecated in favor of `code-review-and-quality` (Addy Osmani) and `receiving-code-review` (Superpowers).

These skills are retained for historical reference and to provide migration clarity for teams updating from older pack versions.
